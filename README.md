# 🎬 Node.js Video API

Este projeto é um sistema de gerenciamento de vídeos construído com Node.js, seguindo os conceitos de API RESTful.

## 🌐 Live Demo
Você pode testar a API rodando aqui: [https://node-js-jnkj.onrender.com](https://node-js-jnkj.onrender.com)

## 🛠️ Instalação e Execução

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/thaisjunges/Node.Js.git

2. **Entre na pasta do projeto:**
    cd Node.Js

3. **Instale as dependências:**
    npm install 

4. **Configure as variáveis de ambiente:**
   **Crie um arquivo .env na raiz do projeto com o conteúdo:**
    DATABASE_URL=seu_link_aqui

5. **Inicie o servidor**
    node server.js
